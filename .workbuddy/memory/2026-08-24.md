## PR #1 自动创建（00:25 起，绕开 gh 交互）
- 用户截图提示：GCM 里实际有 `hdzwzqbxlk` 的 token，**沙箱里 `git credential fill` 拿空不代表本机没 token**——沙箱是沙箱、系统是系统，不能混为一谈。
- 路径选择：`gh pr create` 多次卡死（看似等浏览器/交互），放弃；改用 pwsh MCP + GCM 真实 token + `Invoke-RestMethod` 直接调 GitHub REST API `POST /repos/.../pulls`。
- 关键 3 步模板（**下次 PR 创建直接复用**）：
  1. 从 GCM 拿 token（必须喂完整 stdin，否则 `refusing to work with credential missing host field`）：
     ```
     $stdin=('protocol=https','host=github.com','')-join "`n"
     $cred=$stdin | git credential fill
     $token=($cred -split "`n" | Where-Object { $_ -like 'password=*' } | Select-Object -First 1) -replace '^password=',''
     ```
  2. 必备 header：`Authorization: Bearer $token` + `Accept: application/vnd.github+json` + `X-GitHub-Api-Version: 2022-11-28`
  3. POST `https://api.github.com/repos/{owner}/{repo}/pulls`，body = `{title, head, base, body, draft, maintainer_can_modify}` JSON
- 绕坑点：gh CLI 在本机可能有交互/网络探测卡顿；`gh auth status` 也曾卡 60s。**创建 PR 走 REST API 比走 gh 稳**。
- 经验固化：本机 git/GCM/token → pwsh MCP；Push Gate 走 PR → 直 REST API；gh CLI 仅用作旁路 fallback。
